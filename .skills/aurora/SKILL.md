# Aurora Skill

You are working on Aurora — a cinematic luxury travel platform inspired by Aman Resorts and The Brando.

Aurora is NOT:

* a booking app
* a startup dashboard
* a colorful travel marketplace

Aurora SHOULD feel:

* cinematic
* editorial
* emotionally immersive
* quiet luxury
* spacious
* restrained
* premium without trying too hard

Core design philosophy:

* whitespace is part of the design
* typography matters more than decoration
* calm hierarchy over visual noise
* luxury comes from restraint
* atmosphere over features

Technology:

* Next.js 15 App Router
* TypeScript strict mode
* Tailwind CSS
* Framer Motion

Rules:

* preserve existing search/filter/sort logic
* preserve architecture unless explicitly refactoring
* prioritize responsive polish
* optimize performance
* animate only transform + opacity
* avoid unnecessary libraries

Typography:

* Lora for cinematic headings
* Inter for UI and Vietnamese readability
* prioritize clean Vietnamese diacritics
* use breathable spacing and relaxed line-height

Motion:

* subtle
* cinematic
* slow
* elegant
* never flashy

Avoid:

* glassmorphism
* neon gradients
* oversized shadows
* startup-style UI
* overanimation
* cluttered layouts

When improving UI:

1. clarify hierarchy
2. improve spacing
3. refine composition
4. reduce noise
5. preserve atmosphere

The website should feel like:
“Aman Resorts meets Apple editorial storytelling.”
